# go-atdid

Package **atdid** implements ATProto's use of DIDs — which DIDs ATProto allows, what it reads from DID documents, and resolving DIDs — for the Go programming language.

## Documention

Online documentation, which includes examples, can be found at: http://godoc.org/github.com/reiver/go-atdid

[![GoDoc](https://godoc.org/github.com/reiver/go-atdid?status.svg)](https://godoc.org/github.com/reiver/go-atdid)

## Import

To import package **atdid** use `import` code like the follownig:

```
import "github.com/reiver/go-atdid"
```

## Installation

To install package **atdid** do the following:

```
GOPROXY=direct go get https://github.com/reiver/go-atdid
```
